# Security Policy

## Scope

This repository is a local teaching lab. It contains no service, no
deployment, and no real API. Its vulnerable functions are lab code for
demonstration and testing only.

## Reporting a problem

Open an issue describing the file and the problem. Do not include real
credentials, tokens, personal data, or data from a real API.

## Responsible use

Use the lab to learn detection and remediation. Do not use its
techniques against a real API or a system you do not own, and do not
copy a vulnerable function into a real application — the fixed
function next to it is the one to copy.
